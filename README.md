# EMRIA Editorial V2

Redesign inspired by the *approach* of modern minimal jewelry stores: image-first, editorial typography, compact navigation, category filters and dark/light contrast. It is not a copy of Dione Project.

## Deploy
Upload the **contents** of this folder to the root of your GitHub repository and deploy with Vercel.

Build command: `npm run build`
Output directory: `dist`

This version intentionally loads the existing EMRIA images from `https://www.emriajewelry.com/`, so you do not have to rename/re-upload your current images.

## Important
Before replacing the live site, use a Vercel preview deployment to review the redesign.
