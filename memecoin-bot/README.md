# Bot για meme coins (pump.fun, Solana)

Το bot βλέπει **κάθε νέο meme coin τη στιγμή που βγαίνει** στο pump.fun. Το ελέγχει (δημιουργός, social, αγοραστές, ροή χρημάτων), αγοράζει όσα περνούν τα φίλτρα και τα πουλάει με κανόνες: στόχος, stop-loss, trailing stop, έξοδος αν πουλήσει ο δημιουργός.

**Ξεκινά πάντα σε εικονική λειτουργία (paper):** πραγματική αγορά, ψεύτικα χρήματα, όλες οι χρεώσεις. Πριν από οτιδήποτε άλλο διάβασε το **[ANALYSIS.md](ANALYSIS.md)**: εκεί εξηγείται γιατί οι περισσότεροι χάνουν σε αυτό το παιχνίδι και πώς θα κρίνουμε με νούμερα αν αξίζει.

## Εγκατάσταση (μία φορά, ~15 λεπτά)

### 1. Python
Αν έχεις ήδη την εφαρμογή των μετοχών, το έχεις. Αλλιώς: **Python 3.11 ή νεότερη** από το https://www.python.org/downloads/ (στα Windows τσέκαρε **«Add python.exe to PATH»**).

### 2. Κλειδί API στο PumpPortal (χρειάζεται και για το paper)
Το PumpPortal δίνει τη ζωντανή ροή του pump.fun. Τα νέα coins είναι δωρεάν, οι τιμές τους (συναλλαγές) χρεώνονται **0,01 SOL ανά 10.000**.
1. Άνοιξε το https://pumpportal.fun και πάτα **«Generate API Key»** (Trading API → Create Wallet & API Key).
2. Εμφανίζονται τρία πράγματα: **API key**, **δημόσια διεύθυνση** και **ιδιωτικό κλειδί** του πορτοφολιού που σου έφτιαξε. Αποθήκευσέ τα σε ασφαλές μέρος (π.χ. password manager). Δεν ξαναεμφανίζονται.
3. Στείλε **0,3 SOL** στη δημόσια διεύθυνση. Από εκεί πληρώνονται τα δεδομένα (πρέπει να μένουν πάντα πάνω από 0,02 SOL). SOL αγοράζεις σε ένα ανταλλακτήριο (Binance, Kraken, Coinbase κ.λπ.) και κάνεις ανάληψη στη διεύθυνση, επιλέγοντας δίκτυο **Solana**.

Με τις προεπιλογές το bot ξοδεύει **το πολύ 0,05 SOL τη μέρα** σε δεδομένα (δες ANALYSIS, ενότητα 5).

### 3. Ειδοποιήσεις στο κινητό (προαιρετικό)
Στην εφαρμογή **ntfy** που έχεις ήδη, πάτα **+** και φτιάξε **νέο** θέμα, π.χ. `andreas-meme-8h2k5w`, ξεχωριστό από αυτό των μετοχών.

### 4. Εκκίνηση
- **Windows:** διπλό κλικ στο `start_windows.bat`.
- **Mac:** διπλό κλικ στο `start_mac.command` (αν δεν σε αφήσει: δεξί κλικ → Άνοιγμα).

Την πρώτη φορά εγκαθιστά ό,τι χρειάζεται (1–3 λεπτά) και ανοίγει το αρχείο **`.env`**. Συμπλήρωσε:
```
PUMPPORTAL_API_KEY=το κλειδί από το βήμα 2
NTFY_TOPIC=το θέμα από το βήμα 3
```
Αποθήκευσε, κλείσε το Notepad/TextEdit και πάτα Enter στο μαύρο παράθυρο. Εμφανίζεται μενού:

| Επιλογή | Τι κάνει |
|---|---|
| **1** Εκκίνηση | ξεκινά το bot· για να σταματήσει, κλείνεις το παράθυρο ή πατάς Ctrl+C |
| **2** Έλεγχος | δοκιμάζει σύνδεση, κλειδί API, social links και ειδοποίηση. **Κάν' το πρώτα** |
| **3** Αναφορά | αποτελέσματα ανά στρατηγική (γράφεται και στο `journal/report.md`) |
| **4** Κόστη | πόσο κοστίζει κάθε αγορά+πώληση ανά μέγεθος θέσης |
| **5** Backtest | ξαναπαίζει τις καταγεγραμμένες μέρες με τις τρέχουσες ρυθμίσεις |

Όσο τρέχει το bot, ο υπολογιστής δεν «κοιμάται» (η οθόνη μπορεί να σβήνει). Αν τον κλείσεις, απλώς χάνονται εκείνες οι ώρες.

## Τι βλέπεις όσο τρέχει

- **Στο παράθυρο:** κάθε λεπτό μια γραμμή με τα coins που παρακολουθεί και το αποτέλεσμα κάθε στρατηγικής.
- **`journal/status.md`:** η πλήρης κατάσταση, ανανεώνεται κάθε λεπτό, μαζί με το κόστος δεδομένων.
- **Στο κινητό:** σύνοψη κάθε 12 ώρες (στο live: κάθε αγορά και πώληση).
- **`journal/trades.csv`:** κάθε συναλλαγή (ανοίγει με Excel).

Στείλε μου το `journal/report.md` όποτε θέλεις και το αναλύουμε μαζί. Το κρίσιμο ερώτημα: κερδίζει κάποια στρατηγική το `baseline_all` μετά από όλες τις χρεώσεις, σε 150+ συναλλαγές;

## Πραγματικά χρήματα (live): μόνο μετά τη Φάση 1

> ⚠️ Μόνο αν η Φάση 1 βγάλει στρατηγική που περνά τα κριτήρια της ενότητας 7 του ANALYSIS. Και μόνο με χρήματα που είσαι έτοιμος να χάσεις.

1. **Ξεχωριστό πορτοφόλι:** στο Phantom πρόσθεσε **νέο λογαριασμό** (όχι τον κύριό σου) και κάνε Settings → τον λογαριασμό → **Show Private Key**. Στείλε εκεί **έως 1 SOL**. Το bot αρνείται να δουλέψει αν το πορτοφόλι έχει πάνω από 1,5 SOL.
2. **RPC (δωρεάν):** φτιάξε λογαριασμό στο https://www.helius.dev και αντέγραψε το «RPC URL» (`https://mainnet.helius-rpc.com/?api-key=...`). Χωρίς αυτό χρησιμοποιείται το δημόσιο RPC του Solana, που είναι αργό και συχνά απορρίπτει αιτήματα.
3. Στο `.env`:
   ```
   WALLET_PRIVATE_KEY=το ιδιωτικό κλειδί του νέου λογαριασμού
   RPC_URL=το URL του Helius
   MEMEBOT_MODE=live
   MEMEBOT_I_ACCEPT_RISK=yes
   ```
4. Στο `config.json`, στο `"live"`, όρισε `"strategy"` τη στρατηγική που κέρδισε στη Φάση 1. Προαιρετικά βάλε `feed.sample_pct` 100 για να βλέπει όλα τα νέα coins (ανεβαίνει όμως το κόστος δεδομένων, οπότε ανέβασε αντίστοιχα και το `feed.max_data_sol_per_day`).
5. Τρέξε **2 (Έλεγχος)**: πρέπει να δείξει τη διεύθυνση και το υπόλοιπο του πορτοφολιού. Μετά **1 (Εκκίνηση)**.

Στο live τρέχουν και όλες οι στρατηγικές σε paper, μαζί με ένα paper αντίγραφο της live (στην αναφορά: `momentum_early` και `momentum_early@live`), ώστε να βλέπεις πόσο απέχει η πραγματική εκτέλεση από την εικονική.

### Πώς το σταματάς
| Θέλεις | Κάνεις |
|---|---|
| Καμία νέα αγορά, οι ανοιχτές να κλείσουν κανονικά | φτιάξε αρχείο με όνομα **`STOP`** (ή `STOP.txt`) στον φάκελο. Σβήσ' το για να συνεχίσει |
| Πούλα τα πάντα τώρα | φτιάξε αρχείο **`SELL_ALL`** (ή `SELL_ALL.txt`) |
| Κλείσιμο | κλείσε το παράθυρο ή Ctrl+C: πουλάει πρώτα τις ανοιχτές θέσεις (έως 90″) |
| Επιστροφή στο paper | `MEMEBOT_MODE=paper` στο `.env` |

Αν το bot έκλεισε απότομα (π.χ. έπεσε το ρεύμα), στην επόμενη εκκίνηση βρίσκει τις θέσεις που έμειναν στο πορτοφόλι και τις διαχειρίζεται κανονικά.

### Ασφάλεια του κλειδιού
- Το ιδιωτικό κλειδί μπαίνει **μόνο** στο `.env` στον υπολογιστή σου. Το `.env` δεν ανεβαίνει ποτέ στο GitHub (το εμποδίζει το `.gitignore`).
- **Μην** το γράψεις σε συζήτηση (ούτε με το Claude), email ή σε Telegram bot. Όποιος το έχει, αδειάζει το πορτοφόλι.
- Το `live.broker = "lightning"` δουλεύει χωρίς ιδιωτικό κλειδί στον υπολογιστή, από το πορτοφόλι του PumpPortal (`PUMPPORTAL_WALLET_PUBLIC_KEY`). Χρεώνει όμως 1% αντί για 0,5%, και το κλειδί του το έχει και το PumpPortal.

## 24/7 σε server (VPS, προαιρετικό)

Για να τρέχει χωρίς τον υπολογιστή σου: ένας μικρός server με Ubuntu (π.χ. Hetzner ή DigitalOcean, ~4–6 €/μήνα).
```bash
git clone https://github.com/andrew711994a-netizen/new-design.git
cd new-design/memecoin-bot
bash deploy/install_vps.sh        # εγκαθιστά και το ξεκινά ως υπηρεσία που ξανανοίγει μόνη της
nano .env                         # συμπλήρωσε τα κλειδιά, μετά: sudo systemctl restart memebot
journalctl -u memebot -f          # ζωντανά μηνύματα
```

## Ρυθμίσεις (`config.json`)

| Ρύθμιση | Τι κάνει |
|---|---|
| `feed.sample_pct` | % των νέων coins που παρακολουθεί (30 = τυχαίο δείγμα, για να μένει χαμηλό το κόστος δεδομένων) |
| `feed.max_data_sol_per_day` | ανώτατο κόστος δεδομένων ανά ημέρα |
| `prefilter.*` | ποια coins απορρίπτονται αμέσως (αγορά δημιουργού, κατά συρροή δημιουργοί, λέξεις στο όνομα) |
| `costs.*` | χρεώσεις, καθυστέρηση εκτέλεσης (latency_ms), slippage |
| `strategies[]` | οι στρατηγικές: `entry` = πότε αγοράζει, `exit` = πότε πουλάει. Μπορείς να προσθέσεις δικές σου |
| `live.*` | φρένα του live: ποσό, θέσεις, όρια ημέρας, μέγιστο υπόλοιπο πορτοφολιού |

Αν αλλάξεις στρατηγικές, δες πρώτα τι θα είχαν κάνει στις μέρες που έχουν καταγραφεί: επιλογή **5 (Backtest)**.

## Αρχεία
- `memebot/engine.py`: φίλτρα, αγορές/πωλήσεις, εικονική εκτέλεση, φρένα
- `memebot/strategy.py`: κανόνες εισόδου/εξόδου · `memebot/curve.py`: η καμπύλη του pump.fun και τα κόστη
- `memebot/feed.py`: ροή PumpPortal · `memebot/live.py`: πραγματικές εντολές (υπογραφή, αποστολή, επιβεβαίωση)
- `memebot/runner.py`: ζωντανή λειτουργία · `memebot/backtest.py`, `memebot/report.py`: έρευνα και αναφορές
- `tests/`: 24 αυτόματα τεστ με προσομοιωμένη αγορά (`pip install pytest && pytest`)
- `journal/`: τα αποτελέσματά σου (μένουν μόνο στον υπολογιστή σου)

Δεν αποτελεί επενδυτική συμβουλή. Τα meme coins είναι εξαιρετικά επικίνδυνα και μπορείς να χάσεις όλο το ποσό.
